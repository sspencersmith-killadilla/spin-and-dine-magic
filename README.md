# Spin & Dine

can i create a website that lists all restaurants withing a 5 mile radius of a specific address (entered by the user) that then randomly picks the restaurant the person should go eat at? This should look like a slot machine when it's picking, or a spinning wheel of fortune.  They should be able to pick certain criteria to limit, like "spicy, vegetarian option" etc.
